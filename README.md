# Password Security Tool

A python command line tool to generate secure passwords and check password strength.

## Features 

Random password generation with user controlled length 

Option to include uppercase letters, numbers and symbols bassed on user preference 

Automatically inspects the generated password and reports if it contains lowercase letters, uppercase letters, numbers and symbols

Scoring system that evaluates how complex the password is and displays a rating to the user (Weak, Moderate, Strong or Very Strong)

Menu system to choose between generating a new password or checking the strength of an existing one

## What I learned

Structuring conditional logic to build a character set bassed off user preferences

Using flag variables and loops to check for specific character types

Working with Python 'string' modules (ascii_lowercase, ascii_uppercase, digits, punctuation

Writing functions with parameters and return values and combining them into a menu

Handling invalid user input without crashing the program

Git workflows (branching, merge conflicts and resolving diverged history)

## How to run

python "Password Security Tool.py"

You will be prompted to either generate a new password with options to choose length, uppercase characters, numbers and symbols or check the strength of a password you already have
